# Product profile v1

Scope: dashboards, data tables, forms and multistep product UI. This is a local DaVinci profile: upstream Taste explicitly excludes this scope. Do not import its landing-page rules. Defaults: DESIGN_VARIANCE=4, MOTION_INTENSITY=2, VISUAL_DENSITY=7.

Optimize task completion, legible data and predictable navigation. Preserve units, labels, real content constraints and existing brand tokens. Provide empty, loading, error, success and disabled states. Use semantic labels, visible focus, keyboard controls and adequate targets. Show mobile overflow or responsive table behavior deliberately. Distinct concepts should explore information organization and workflow. Respect reduced motion. Mock APIs must be labeled and never reported as integrated. User brand and accessibility override aesthetic preferences. Only React, CSS and local bundled files are available; do not install dependencies or fetch assets. Evidence describes actual checked states only.
