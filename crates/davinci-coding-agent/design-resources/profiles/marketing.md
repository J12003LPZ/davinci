# Marketing profile v1

Scope: landing pages, portfolios and marketing redesigns. Use complete pinned Taste sections 0, 1, 11, 13 and 14. Read the actual audience, content and brand before choosing a direction. Defaults: DESIGN_VARIANCE=7, MOTION_INTENSITY=4, VISUAL_DENSITY=4. These are DaVinci overrides of upstream 8/6/4, favoring readable, reduced-motion previews.

Explicit user brand, factual content, accessibility and security requirements take priority over stylistic preferences. Purple is valid when it belongs to the brand. Produce distinct information hierarchy and composition for alternative concepts, not palette swaps. Preserve real copy; label all mock integrations. Do not install packages, fetch assets/fonts, or execute project configuration. The preview supports React, CSS and bundled local files only. Unsupported frameworks, libraries, icons or image generation remain declared limitations. Never represent a preview as a production implementation.
