# Document profile v1

Scope: reports, editorial documents, proposals and reading experiences. This is a local DaVinci profile, not an assertion that upstream Taste covers documents. Defaults: DESIGN_VARIANCE=5, MOTION_INTENSITY=1, VISUAL_DENSITY=4.

Prioritize reading order, accurate content, citations supplied in the brief, headings and tables with units. Preserve full content and meaningful pagination/print layout. Alternative concepts vary hierarchy and navigation while retaining the same facts. Use readable measure, contrast, semantic HTML and keyboard access. Preserve user typography and brand; serif and purple are valid where requested. Respect reduced motion and avoid decorative animations. Only React, CSS and local files are available; no dependency or asset downloads. Never invent citations or mark unknown evidence as verified.
