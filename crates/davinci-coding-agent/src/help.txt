davinci - AI coding assistant with read, bash, edit, write tools

Usage:
  davinci [options] [--] [@files...] [messages...]

Commands:
  davinci voice status|devices|model list   Experimental local CPU dictation setup
  davinci voice model install <id>         Download an approved tiny/base/small model
  davinci voice model import <id> <path>   Verify and import a local model (offline)
  davinci install <source> [-l]     Install extension source and add to settings
  davinci remove <source> [-l]      Remove extension source from settings
  davinci uninstall <source> [-l]   Alias for remove
  davinci update [source|self]   Update davinci, extensions, or model catalogs
  davinci list                      List installed extensions from settings
  davinci config [-l]               Open TUI to enable/disable package resources (Tab switches scope)
  davinci plugin [help]             Claude Code / Codex plugins: browse, install, import, approve hooks
  davinci auth <command>            Print credentials or check provider readiness
  davinci server --listen unix:///path   Experimental protocol server
  davinci client --connect unix:///path  Experimental protocol client
  davinci <command> --help          Show help for install/remove/uninstall/update/list/config/auth/server/client

Options:
  --provider <name>              Provider name (default: google)
  --model <pattern>              Model pattern or ID (supports "provider/id" and optional ":<thinking>")
  --api-key <key>                API key (defaults to env vars)
  --system-prompt <text>         System prompt (default: coding assistant prompt)
  --append-system-prompt <text>  Append text or file contents to the system prompt (can be used multiple times)
  --mode <mode>                  Output mode: text (default), json, or rpc
  --print, -p                    Non-interactive mode: process prompt and exit
                                Unresolved approval emits approval_required JSON and exits 1
  --continue, -c                 Continue previous session
  --resume, -r                   Select a session to resume
  --session <path|id>            Use specific session file or partial UUID
  --session-id <id>              Use exact project session ID, creating it if missing
  --fork <path|id>               Fork specific session file or partial UUID into a new session
  --session-dir <dir>            Directory for session storage and lookup
  --no-session                   Don't save session (ephemeral)
  --name, -n <name>              Set session display name
  --models <patterns>            Comma-separated model patterns for Ctrl+P cycling
  --no-tools, -nt                Disable all tools by default (built-in and extension)
  --no-builtin-tools, -nbt       Disable built-in tools by default but keep extension/custom tools enabled
  --tools, -t <tools>            Comma-separated allowlist of tool names to enable
  --exclude-tools, -xt <tools>   Comma-separated denylist of tool names to disable
  --permission-mode <mode>       manual (default), accept-edits, plan-mode, auto, always-approve
                                 Legacy aliases ask, edits, and read-only are also accepted.
  --sandbox <preset>             Same flag, Codex names: read-only, workspace-write, full-access (a policy preset, not an OS sandbox)
  --thinking <level>             Set thinking level: off, minimal, low, medium, high, xhigh, max
  --extension, -e <path>         Load an extension file (can be used multiple times)
  --no-extensions, -ne           Disable JS extension discovery (native intelligence stays enabled)
  --no-mcp                      Skip all MCP server connections for this run
  --skill <path>                 Load a skill file or directory (can be used multiple times)
  --no-skills, -ns               Disable skills discovery and loading
  --prompt-template <path>       Load a prompt template file or directory (can be used multiple times)
  --no-prompt-templates, -np     Disable prompt template discovery and loading
  --theme <path>                 Load a theme file or directory (can be used multiple times)
  --use-theme <name[/name]>      Set the initial interactive theme for this run
  --no-themes                    Disable theme discovery and loading
  --no-context-files, -nc        Disable AGENTS.md and CLAUDE.md discovery and loading
  --export <file>                Export session file to HTML and exit
  --list-models [search]         List available models (with optional fuzzy search)
  --verbose                      Force verbose startup (overrides quietStartup setting)
  --tui-mode <mode>              TUI mode: regular (default) or fullscreen
  --legacy-tui                   Open the previous chrome instead of the davinci shell
  --approve, -a                  Trust project-local files for this run
  --no-approve, -na              Ignore project-local files for this run
  --offline                      Disable startup network operations (same as PI_OFFLINE=1)
  --                             End option parsing; treat remaining arguments as messages/files
  --help, -h                     Show this help
  --version, -v                  Show version number

Native intelligence (also available in -p and with --no-extensions):
  tool_search discovers graph_run, memory_search, retrieve_output, and lsp_* tools.
  TypeScript/JavaScript, Rust, and Python semantic servers start only on demand.
  DaVinci never installs a language server, Rust component, or Python environment automatically.
  /lsp-status, /governor-status, /memory-status show native service health.
  Use --no-mcp for small tasks that only need native tools.

Extensions can register additional flags (e.g., --plan from plan-mode extension).

Examples:
  # Print a provider API key for an external client
  davinci auth print-api-key --provider openai

  # Print an OAuth bearer token for an external client (refreshes if expired)
  davinci auth print-bearer-token --provider openai-codex

  # Interactive mode
  davinci

  # Interactive mode with initial prompt
  davinci "List all .ts files in src/"

  # Include files in initial message
  davinci @prompt.md @image.png "What color is the sky?"

  # Non-interactive mode (process and exit)
  davinci -p "List all .ts files in src/"

  # Prompt beginning with a dash
  davinci -p -- "- Summarize these points"

  # Multiple messages (interactive)
  davinci "Read package.json" "What dependencies do we have?"

  # Continue previous session
  davinci --continue "What did we discuss?"

  # Start a named session
  davinci --name "Refactor auth module"

  # Use different model
  davinci --provider openai --model gpt-4o-mini "Help me refactor this code"

  # Use model with provider prefix (no --provider needed)
  davinci --model openai/gpt-4o "Help me refactor this code"

  # Use model with thinking level shorthand
  davinci --model sonnet:high "Solve this complex problem"

  # Limit model cycling to specific models
  davinci --models claude-sonnet,claude-haiku,gpt-4o

  # Limit to a specific provider with glob pattern
  davinci --models "github-copilot/*"

  # Cycle models with fixed thinking levels
  davinci --models sonnet:high,haiku:low

  # Start with a specific thinking level
  davinci --thinking high "Solve this complex problem"

  # Read-only mode (no file modifications possible)
  davinci --tools read,grep,find,ls -p "Review the code in src/"

  # Disable one tool while keeping the rest available
  davinci --exclude-tools ask_question

  # Export a session file to HTML
  davinci --export ~/.davinci/agent/sessions/--path--/session.jsonl
  davinci --export session.jsonl output.html

Permission Modes (interactive):
  Shift+Tab                       Cycle Manual -> Accept Edits -> Plan Mode -> Auto Mode
                                  -> Always Approve -> Manual (idle composer only)
  Alt+Shift+T                     Cycle thinking level (where supported)
  /permissions [mode]             Show the mode picker or select a named mode
  /plan                           Enter read-only planning
  /plan show | /plan diff          Inspect the current plan or its latest revision
  /plan edit <id> <text>           Edit one decision without replacing the whole plan
  /plan accept <id>               Accept one plan decision; "all" selects all decisions
  /plan reject <id>               Reject one plan decision; "all" selects all decisions
  /plan approve                   Approve a fresh, complete plan without changing mode
  /plan accept [mode]             Approve and select an execution mode
  /act                            Leave Plan Mode without implicitly approving a plan
  Always Approve removes harness approval prompts, not explicit denials, filesystem
  boundaries, OS restrictions, or missing credentials. Auto Mode escalates risk.

Built-in Tool Names:
  read       - Read file contents
  bash       - Execute bash commands
  powershell - Execute PowerShell commands on Windows
  edit       - Edit files with find/replace
  write      - Write files (creates/overwrites)
  grep       - Search file contents (read-only, off by default)
  find       - Find files by glob pattern (read-only, off by default)
  ls         - List directory contents (read-only, off by default)
