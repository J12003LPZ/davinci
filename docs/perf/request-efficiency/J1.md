# J1 — bounded Jev advice integration

Status: **implemented as an opt-in shadow experiment; no default promotion**.

`prepare_turn_decision(DecisionSnapshot)` is now the shared admission point for
print and interactive submissions. It submits at most one shadow request using
the existing runtime worker, keeps the caller path nonblocking, and stores at
most one successful result. A later submission consumes only a result whose
request ID, runtime generation, evidence revision, mutation revision, and
embedded request state all match. Disable, provider replacement, generation
changes, stale evidence, and late results clear or reject the mailbox.

The first coding request uses the deterministic effort policy. A ready result
can only raise an adaptive request's supported effort at construction time;
fixed policy and explicit `Off` remain authoritative. No request is cancelled,
reissued, or rewritten after provider dispatch. `effortAdvice`,
`completionAdvice`, and `toolFamilyAdvice` default to false and require the
existing user-level decision-intelligence enablement. Completion and family
routing remain reserved shadow-only arms until separately calibrated and
measured.
