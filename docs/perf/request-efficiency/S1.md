# S1 — reasoning-summary omission

## Decision

The omission arm is a viable measured candidate for DaVinci's default reasoning-summary setting, but this screening result does not promote it automatically. DaVinci kept the same aggregate correctness (22/24) in both arms, while the omission arm reduced paired median wall time by 4.15 seconds and total wall time by 118.49 seconds. The only paired correctness mismatch was `t2-duration` repetition 2; both arms independently missed that task in other repetitions, so it is recorded as model variance rather than a summary-specific regression. The current default remains unchanged pending the later plan decision gate.

## Wire and precedence checks

`crates/davinci-ai/src/stream.rs` now has a focused wire test covering:

- `reasoningSummary=none` omits `reasoning.summary` while retaining medium reasoning effort;
- `auto`, `concise`, and `detailed` preserve their existing summary behavior;
- a no-reasoning route omits the reasoning object altogether.

The test passed with `cargo test -p davinci-ai --lib reasoning_summary_wire_controls_keep_medium_effort --offline --locked -- --test-threads=1`. Existing focused tests for conservative control values, optional service tier, effort-policy parsing, and service-tier parsing also passed. Whole-file rustfmt was not re-run because `stream.rs` already contains unrelated formatting differences in the dirty tree; `git diff --check` passed for the changed file.

The benchmark runner removes inherited `DAVINCI_*` and `PI_*` environment variables before launching the isolated agent. Coding-agent startup then applies `settings.reasoningSummary`, so the settings fixture is the winning source. Both campaign manifests record the intended effective value (`auto` or `none`), which is the controlled precedence evidence for this arm.
