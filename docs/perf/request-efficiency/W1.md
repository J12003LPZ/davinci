# W1 — Codex prewarm evidence gate

Status: **closed conservatively; no production prewarm change promoted**.

The normal DaVinci print and interactive submission paths do not call
`CodexTransportPool::should_send_prewarm` or construct a `generate: false`
request. That pool method is bounded shape bookkeeping, and the
`CodexFeatureFlags::prewarming` and capability fields are compatibility
plumbing. The only request generator is the explicit maintainer-only
`--codex-probe` command in `crates/davinci-coding-agent/src/codex_probe.rs`.
