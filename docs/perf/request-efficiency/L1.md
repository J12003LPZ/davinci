> Historical record. Acceptance and verification claims below are superseded by
> [the September 27 evidence correction](FINAL.md). Raw campaigns and builds
> were not independently revalidated here; this is not current promotion,
> parity, or runtime-correctness evidence.

Status: accepted as a diagnostic screening checkpoint; no default promotion.
The lean surface kept specialist discovery reachable and reduced DaVinci wall
time in this screen, but it increased logical/tool work and did not establish a
request reduction. One parent-pass/candidate-fail row remained in `t5-csv`;
its failure is a model output variance (lowercased region keys), not a tool
surface error. The first-request token counts are recorded; the current event
stream does not expose serialized schema count/bytes, so those two measures
remain unverified rather than inferred from the tool names.

## Changes

`crates/davinci-agent/src/runtime/capabilities.rs` now carries explicit,
optional capability-family metadata. Built-in registrations use an explicit
family table rather than treating a name prefix as authority. The runtime
search path filters authorization before exposure and supports exact family
lookup, exact tool lookup, bounded search pagination, and idempotent family
activation.

`crates/davinci-agent/src/tools.rs` defines the lean initial CLI core as
`read`, `grep`, `find`, `ls`, `exec_command`, `write_stdin`, `apply_patch`,
`batch`, `tool_search`, `update_plan`, `propose_plan`, `ask_user_question`,
`agent`, `job_output`, `job_kill`, and Windows `bash`. Deferred tools remain
discoverable. Family lookup activates every authorized schema-bearing member,
while schema-less and denied members remain unavailable. Runtime-less MCP
fallback remains name-only and does not claim schema activation.

## Failure review and decision

The Lean parent-pass/candidate-fail row is DaVinci `t5-csv`, repetition 1.
Re-running its frozen output directory's hidden tests gives four failures:
`region_totals` returns lowercase `north`, `south`, `east`, and `a`, while the
contract requires preserving the input capitalization. The fixture also covers
BOM/whitespace and currency/thousands parsing. The same campaign passes t5 in
the other DaVinci repetitions and has variable Codex t5 outcomes; the earlier
same-campaign ten-run t5 A/B also failed once on the baseline and passed all
ten B0 runs. This is recorded as model variance, not a repeated L1 runtime
regression.

Decision: retain the explicit family/lean implementation and evidence, do not
make Lean the default based on this screen, and continue to G1 with the fixed
tool policy and effort. The current telemetry gap for schema count/bytes is
kept explicit in the next checkpoint rather than filled with an estimate.
