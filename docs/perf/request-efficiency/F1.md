## Observed failures

The legacy failures are sparse and variable. DaVinci had one t2-duration failure
(16/17 tests) in repetition 2. Codex had t5-csv failures in repetitions 1 and
2, one t2-duration failure in repetition 2, and one t3-lru failure in repetition
2. The earlier same-campaign t5 A/B control also showed baseline variance (9/10
versus 10/10), so these rows do not justify an F1-specific regression claim.

The large fixtures failed in all 12 rows for each harness. m1-config-parser and
m2-public-api-migration failed the same public-test subsets in every repetition;
m3-state-persistence also failed in every repetition; m4-cli-feature produced
partial repairs, with one DaVinci row reaching the 900-second per-row timeout.
This is a stable capability/fixture result under the pinned model and settings,
not evidence that the DaVinci release binary changed identity or leaked work.
