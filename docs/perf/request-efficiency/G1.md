# G1: request-completion guidance

Status: candidate-only; preview guidance was not promoted as the default.
The stable profile remains the accepted prompt configuration. The preview
screen had one paired parent-pass/candidate-fail row caused by a real boundary
case that the preview model implementation missed, and it was slower in the
paired DaVinci median. The prompt change is retained for further work without
claiming a quality or latency improvement.

## Changes

`crates/davinci-agent/src/prompt/coding.rs` adds the candidate
`coding.request-workflow` module. It tells the model to read named files and
applicable instructions directly, batch independent reads, make one coherent
minimal patch, include the smallest meaningful verification when ordering is
known, inspect failures, compare every explicit requirement with a concrete
observable, and report actual verification. It explicitly avoids an
arbitrary request-count stopping rule.

`crates/davinci-agent/src/prompt/verification.rs` adds the candidate
`verification.requirement-checks` module. It aligns the no-suite fallback with
the classifier used by the verification path: a short `python -c` or heredoc
imports the changed module and checks normal, boundary, and invalid inputs.
The same classifier wording is used for every route, and unverified
requirements remain explicit.

`crates/davinci-agent/src/prompt/bundle.rs` composes these modules in the new
preview-v4 bundle while keeping the legacy prompt constants and stable bundle
unchanged. `prompt/mod.rs`, `prompt/version.rs`, `prompt/astra.rs`,
`prompt/composer.rs`, and the coding-agent prompt-profile test were updated for
the versioned preview profile. The existing OpenAI provider adapter already
contained the required parallel/batch and concise guidance and its 250-token
budget tests remain the coverage for that route; no provider-adapter source
change was necessary.

## Failure review and decision

The sole comparison failure is DaVinci preview `t2-duration`, repetition 1.
The preview model used `r"(\\d+(?:\\.\\d+)?)([dhms])"`, which rejects the
required boundary forms `.5s` and `1.s`. The stable row used
`r"(\\d+(?:\\.\\d*)?|\\.\\d+)([dhms])"` and passed those cases. The failure
is therefore a concrete requirement miss in the sampled preview behavior, not
a harness or tool-surface error. All three preview `t5-csv` repetitions passed;
the earlier same-campaign ten-run t5 A/B already established baseline variance
(9/10) with B0 at 10/10.

Decision: keep the new modules and tests as a candidate preview profile, leave
the stable profile as default, and proceed to the independent summary and
adaptive-effort experiments. No prompt promotion is justified by this screen.
