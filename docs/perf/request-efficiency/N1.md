# N1: canonical tool-name ingress

Status: accepted local correctness checkpoint, with model-variance and performance
limitations below. Parent: V1 commit `0d4401f0`.

## Changes

One shared resolver gives exact registered names priority, including disabled
or denied registrations. Otherwise it removes exactly one `functions.` prefix
only when the remainder is registered and does not have another such prefix.
Other namespaces, empty suffixes and unknown names remain unchanged.

Direct provider calls and batch children resolve before scheduling, permission
checks, hooks, mutation accounting and execution. Preparation, execution and
finalization also apply the same idempotent resolver for internal entry points.
Provider messages retain the original spelling; call IDs are unchanged. The
existing ledger/journal replay policy is preserved.

## Regression evidence

Five new tests failed before implementation: alias mapping, registration
precedence, direct dispatch, policy/scheduling, and batch behavior. A test
expectation initially assumed automatic replay of a completed write; inspection
confirmed the existing mutating-tool policy requires reconciliation. The test
now asserts that policy and verifies the file is not overwritten.

The focused name run passed 9 tests, including a scripted model that emits
aliased writes and terminal checks directly and through `functions.batch`.
It completes in the expected 3/2 model calls without reminders or automatic
verification, while retaining the original spelling in message history.
The batch filter passed 18 tests and operation-dispatch integration passed 9.
The final name-filter run passed all 9 tests after the exact-registration denial
case was added. `git diff --check` passed. Release and replay builds passed offline.

No dependency, toolchain, prompt, permission or installed-executable changes.

## Failure review and decision

N1 duration repetition 2 and Codex duration repetitions 0 and 2 each passed 16/17.
Grader-only rechecks reproduced the same trailing-whitespace failure in all three.
The frozen parent V1 already reproduced that exact failure in repetitions 1 and 4
of `ab-duration-v1-20260926`; B0 reproduced it three times in the same A/B.
See [V1 duration A/B](V1-duration-ab.md). No hidden tests or grader changes were
made, and no hidden test was supplied to either benchmark model.

The complete N1 screen emitted no `functions.` names in provider calls or batch
children. Canonical names take the unchanged exact-registration path. Combined
with unchanged replay and the previous parent reproduction, the evidence supports
shared model variance rather than an alias-dispatch regression. Per the owner's
standing instruction, retain the failure and continue without an approval pause.
Another identical duration A/B is not needed to establish that the parent can fail.

Accept N1 for its deterministic ingress correction, supported by focused policy,
scheduler, mutation, replay and direct/batch scripted regressions. The live screen
checks surrounding behavior but does not exercise the corrected alias path or prove
performance improvement. No permission, verification or replay policy was weakened.
