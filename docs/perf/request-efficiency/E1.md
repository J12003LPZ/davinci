compaction. Visual guidance depends on relevant work, including batched requests.

## Failure and guidance audit

Parent-pass/candidate-fail: t2-duration repetition 1. E1 duration repetitions 1
and 2 each pass 16/17 grader cases, failing valid trailing whitespace. Parent N1
repetition 2 already has this failure; the prior five-per-arm duration A/B also
reproduced it in both B0 and V1. This does not erase E1's observed pass loss.
Same-campaign Codex duration repetitions 0/1 fail the same requirement. Codex CSV
repetition 0 passes 2/4 (export/BOM whitespace); calculator repetition 1 passes
10/18 after making no changes. Grader-only rechecks of all six failures reproduced
them after models terminated. No grader or task was changed.

Initial listing-only requests: zero in both N1 and E1. Reviewed genuine check
commands recognized by the actual classifier: N1 27/42 (64.3%), E1 20/65 (30.8%).
The review excludes source searches/diagnostics and includes explicit exception
and CLI exit checks missed by the marker heuristic. Raw audit and review records
are retained in each campaign. Recognition is not execution success or freshness;
this audit uses final changed paths, not historical mutation generations.

E1 often sent multiline python through PowerShell, PowerShell here-string pipes,
or encoded exec source; these are conservatively unsupported by the existing
classifier. Revealing the actual shell may have steered those choices, but this
is an observed mechanism, not a causal ablation. Shared guidance failed to explain
the supported shell forms. E1 had 33 requests after reminders versus N1's 14;
no automatic verifications, post-reminder mutations, unrelated changes, or
transaction leaks occurred in either arm.

Decision: reject this candidate as an efficiency improvement. Requests, total
wall time, reminders and uncached tokens worsened; no listing round was removed.
Retain the entire failed campaign. Revise only the shared guidance to distinguish
single-line PowerShell checks from multiline Bash checks, test the actual forms
against the unchanged classifier, then screen the revised candidate. Do not
weaken evidence requirements or treat model variance as an efficiency success.
