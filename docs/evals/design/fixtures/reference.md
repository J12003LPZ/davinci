# Frozen offline reference, version 1

Use the supplied content verbatim where a fixture requires preservation.
Do not invent customer endorsements, business metrics, integrations or API results.
Every primary control has an accessible name and a visible keyboard focus state.
Preserve title, document language and reading order. No horizontal overflow at
390 x 844, 768 x 1024 or 1440 x 900. Content and navigation remain usable with
reduced motion. Test the named empty, error, loading and success states.

Concepts differ in composition and typography, not only color. Product work
preserves the target's established components and routes. Marketing profiles
cannot silently override brand or accessibility requirements. Documents and
slides prioritize reading order, grouping and legible long-form content.

Source-only output, missing runtime, unknown usage, mock integration and missing
browser evidence remain incomplete. Revoked permissions and forbidden network
or filesystem requests are denied. A generated screenshot is never production
verification. Negative fixtures do not qualify for a visual preference score.

This is an authored evaluation rubric, not an observed benchmark result.
